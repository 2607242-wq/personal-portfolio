# Personal Portfolio

A responsive personal portfolio website for **Patel David Sanchez**, a computing student at KCA University (KCAU). Built for Web Assignment 2 using only HTML and CSS.

**Live site:** https://2607242-wq.github.io/personal-portfolio/

## Pages and sections
- **Home:** name, profile picture, short introduction
- **About Me:** education table, interests list, project steps list
- **Skills:** six technical skills
- **Projects:** AliMedix Online Pharmacy, AliMedix Pharmacy POS, KCAU Study Planner
- **Contact:** email link and contact form

## Built with
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- External CSS (`style.css`) with classes, IDs, Flexbox and Grid
- Hover effects on navigation links and buttons
- Mobile-friendly layout using a media query

## Project structure
```
personal-portfolio/
├── index.html
├── style.css
├── README.md
└── images/
```

## Run it locally
Download or clone the repository, then open `index.html` in any browser.
